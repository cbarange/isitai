A network protocol is simply an agreed set of rules for exchanging data between machines. Most descriptions organise those rules as layers, each one providing a specific service to the layer above it. The physical layer moves bits across a medium, the link layer handles frames between directly connected devices, and the network layer takes care of logical addressing and routing. Above that, the transport layer splits data streams into segments and may guarantee ordering and delivery. TCP does exactly this, opening a connection through a three-way handshake before any payload is sent. The client sends a synchronisation segment, the server acknowledges it and offers its own sequence number, and the client confirms. That exchange looks expensive, but it lets both sides agree on starting sequence numbers and receive window sizes. UDP offers a connectionless alternative that is faster but never retransmits, which suits streaming media and fast-paced games.
